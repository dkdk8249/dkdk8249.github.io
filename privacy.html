개인정보처리방침

Bedtime Story Uploader · 최종 수정일 2026년 9월 19일

1. 개요

Bedtime Story Uploader(이하 "본 도구")는 잠자리 동화 영상을 자동으로 렌더링해 운영자 본인이 소유한 YouTube 채널에 업로드하는 개인용 자동화 도구입니다. 본 도구는 운영자 본인의 계정에서만 동작하며, 일반 이용자에게 제공되는 서비스가 아닙니다.

2. 수집하는 정보

본 도구는 이용자로부터 어떠한 개인정보도 수집하지 않습니다. 회원가입 절차가 없고, 방문자를 추적하는 분석 도구나 광고 스크립트를 사용하지 않으며, 쿠키를 설정하지 않습니다.

3. Google 사용자 데이터의 이용

본 도구는 운영자가 직접 승인한 범위 안에서 다음 Google 권한을 사용합니다.

https://www.googleapis.com/auth/youtube.upload
운영자 본인 채널에 영상 파일을 업로드하는 데에만 사용합니다.

https://www.googleapis.com/auth/youtube.readonly
업로드 대상 채널이 올바른지 확인하기 위해 채널 이름과 채널 ID만 조회합니다.

본 도구가 접근하는 데이터는 운영자 본인의 YouTube 채널 정보뿐입니다. 영상 시청 기록, 구독 정보, 댓글, 다른 이용자의 데이터에는 접근하지 않습니다.

4. 인증 정보의 보관

OAuth 인증으로 발급된 갱신 토큰(refresh token)은 GitHub Actions의 암호화된 시크릿 저장소에 보관되며, 영상 업로드를 실행하는 순간에만 사용됩니다. 토큰은 로그에 출력되지 않고, 외부로 전송되지 않으며, 제3자와 공유되지 않습니다. 운영자는 Google 계정 보안 설정에서 언제든 접근 권한을 철회할 수 있습니다.

5. 정보의 제3자 제공

본 도구는 Google API로부터 받은 정보를 제3자에게 판매, 양도, 공유하지 않습니다. 정보는 광고 목적으로 사용되지 않으며, 사람이 열람하지 않습니다.

6. Limited Use 준수

본 도구가 Google API로부터 받은 정보를 이용하거나 다른 앱으로 전송하는 행위는 Google API Services User Data Policy를 준수하며, 여기에는 Limited Use 요건이 포함됩니다.

Bedtime Story Uploader's use and transfer of information received from Google APIs to any other app will adhere to Google API Services User Data Policy, including the Limited Use requirements.

7. YouTube API 서비스

본 도구는 YouTube API 서비스를 사용합니다. 본 도구를 사용함으로써 운영자는 YouTube 서비스 약관에 동의하게 됩니다. Google의 개인정보 처리에 관한 사항은 Google 개인정보처리방침에서 확인하실 수 있습니다.

운영자는 Google 계정 보안 설정에서 본 도구의 접근 권한을 언제든지 철회할 수 있습니다.

8. 데이터 보관 기간

본 도구는 Google 사용자 데이터를 별도로 저장하지 않습니다. 채널 확인을 위해 조회한 정보는 실행 중 메모리에만 존재하며 종료와 함께 사라집니다. 갱신 토큰은 운영자가 삭제하거나 권한을 철회할 때까지만 유지됩니다.

9. 아동 관련 사항

본 도구가 업로드하는 영상은 아동용으로 고지됩니다. 다만 본 도구 자체는 아동을 포함한 어떠한 이용자로부터도 개인정보를 수집하지 않습니다.
