Bedtime Story Uploader

잠자리 동화 영상을 자동으로 만들어 운영자 본인의 YouTube 채널에 올리는 개인용 자동화 도구

무엇을 하는 도구인가

동화 대본과 삽화, 내레이션 음성을 받아 한 편의 영상으로 렌더링한 뒤, 운영자 본인이 소유한 YouTube 채널에 업로드합니다. 렌더링은 GitHub Actions에서, 업로드는 YouTube Data API v3로 이루어집니다.

동작 방식

  • 대본과 소재를 모아 자막·배경음악이 들어간 1080p 영상으로 렌더링합니다.
  • 채널 인트로를 앞에 붙이고 산출물을 검증합니다.
  • 완성본을 운영자의 Google Drive에 보관합니다.
  • YouTube Data API v3로 운영자 채널에 업로드합니다. 기본 공개 범위는 비공개입니다.

사용하는 Google 권한

youtube.upload — 운영자 채널에 영상을 업로드합니다.

youtube.readonly — 업로드 대상 채널이 올바른지 확인합니다.

이 도구는 운영자 본인의 계정에서만 동작합니다. 일반 이용자를 위한 서비스가 아니며, 다른 사람의 계정이나 채널에 접근하지 않습니다.

수집하는 정보

이 도구는 이용자 정보를 수집하지 않습니다. 자세한 내용은 개인정보처리방침에서 확인하실 수 있습니다.
